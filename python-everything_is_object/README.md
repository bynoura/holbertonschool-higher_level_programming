# Python - Everything is object

This project examines how Python handles objects and explores the distinctions between mutable and immutable data types.

## What You'll Learn

By completing this project, you will understand:

* The concept of objects in Python
* Distinguishing between classes, objects, and instances
* Mutable vs immutable objects and their behaviors
* References and how they work
* Variable assignment mechanics
* Aliasing in Python
* Checking if two variables are identical
* Verifying if two variables reference the same object
* Getting the memory address of a variable (variable identifier)
* Built-in mutable data types
* Built-in immutable data types
* How Python handles function parameters
